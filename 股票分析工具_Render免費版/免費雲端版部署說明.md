# 股票分析工具：Render 免費版部署說明

這一版可以放到 Render 免費方案，部署後會得到一個網址，例如：

`https://stock-indicator-analyzer-xxxx.onrender.com`

手機、平板、電腦只要有網路就能開，不需要跟家裡電腦同一個 Wi‑Fi。

## 免費版限制

- 可以先不用付費。
- 免費服務可能會休眠。
- 休眠後第一次打開會比較慢，通常等一下再重新整理即可。
- 如果以後想要更穩定、不休眠，再升級付費方案。

## 你需要準備

1. 一個 GitHub 帳號。
2. 一個 Render 帳號，可以用 GitHub 登入。

## 部署步驟

### 1. 把這個資料夾上傳到 GitHub

要上傳的主要檔案包含：

- `server.js`
- `package.json`
- `render.yaml`
- `.node-version`
- `public/`

Windows 的 `.cmd` 啟動檔只是在本機使用，雲端部署不需要，但留著也沒關係。

### 2. 到 Render 建立服務

1. 打開 Render。
2. 選 New。
3. 選 Blueprint。
4. 連接你的 GitHub repository。
5. Render 會讀取 `render.yaml`。
6. 方案選 Free。
7. 按 Deploy。

### 3. 完成後取得網址

Render 部署完成後，會給你一個網址。

之後手機直接開那個網址即可。

Android 手機可以用 Chrome 選單「加入主畫面」，會像 App 一樣打開。

## 雲端版和本機版差異

- 本機版：網址通常是 `http://127.0.0.1:8787/` 或區網 IP，只能在電腦或同 Wi‑Fi 使用。
- 雲端版：網址是 Render 給的 `https://...onrender.com`，外面也能使用。

## 如果部署後無法分析

可能原因：

- Render 免費服務剛睡醒，請等 30 秒後重新整理。
- Yahoo 或交易所資料來源暫時回應慢。
- 股票代號不存在，或市場選錯。

台股上市可用自動判斷或 `.TW`，上櫃可用自動判斷或 `.TWO`。
